The Category

The mapping layer between drone data and your system of record.

Drone inspection has been solved. Enterprise maintenance systems have been solved. The seam between them has not. Findings land as JPEGs and PDFs; the CMMS never hears about them. A planner retypes a roof report into Maximo by hand — when they get to it at all.

Stratum Connector is the middleware that closes that seam. Think Zapier, Segment, or Fivetran — but purpose-built to translate drone-detection findings into failure codes, severity into priority, and imagery into asset-tagged service requests inside the CMMS you already run.

The Value Chain

Discover → Structure → Push

The connector sits in the middle of the drone-to-CMMS pipeline. Capture happens upstream. The system of record lives downstream. Stratum is the layer that makes one talk to the other.

01

Discover

Drone platforms and processing engines produce detections — corrosion, cracking, thermal anomalies, blocked drains, membrane damage. Stratum ingests that output from any platform's export format, along with EXIF metadata: GPS, timestamp, altitude, and sensor type.

02

Structure

The mapping catalog matches each detection class to your CMMS failure codes, translates severity to your priority field per asset class, and resolves imagery to a specific asset ID. Nothing is guessed — a human-validated triage queue sits between detection and system of record.

03

Push

Structured findings become native service requests or work orders via the CMMS's own API — Maximo MXSR, SAP PM, Fiix REST, Dynamics 365, ServiceNow. Completion feedback flows back to build program-level trend data and a defensible condition history.

What Stratum Connector Does

Three moving parts. One structured work order.

Any drone platform in

Ingest from DroneDeploy, Skydio, DJI Terra, Pix4D, WebODM, or a custom pipeline. Connectors read each platform's native export format and extract EXIF metadata on every image. No single-vendor lock-in on the capture side.

Structured mapping

The mapping catalog translates detection findings into your failure codes and severity into your priority field, tuned per asset class. Imagery resolves to an asset ID. A human-validated triage queue sits between detection and CMMS — because a garbage work order is worse than none.

Any CMMS out

Push native records via the CMMS's own API: Maximo MXSR, SAP PM, Fiix, Dynamics 365, ServiceNow. Every finding is tagged SOURCE_SYSTEM = STRATUM so leadership can answer, in one query, exactly what the drone program produced.
